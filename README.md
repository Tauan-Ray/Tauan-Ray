# 👋 Olá, eu sou Tauan Ray

Sou desenvolvedor Full Stack e estudante de Análise e Desenvolvimento de Sistemas, com experiência no desenvolvimento de aplicações web, APIs, microserviços e automações com IA.

Atuo principalmente com TypeScript, React, Next.js, Node.js e NestJS, construindo interfaces, serviços backend, integrações entre sistemas e soluções voltadas para problemas reais de produto.

Tenho experiência com APIs REST e GraphQL, bancos de dados relacionais, CI/CD, Kubernetes, observabilidade e aplicações de IA utilizando agentes, prompts e traces.

---

# 🚀 Especialidades

- Desenvolvimento de aplicações full stack, desde interfaces responsivas até APIs e serviços backend
- Criação e integração de APIs REST e GraphQL em arquiteturas de microserviços
- Modelagem e integração com bancos de dados relacionais e não relacionais
- Desenvolvimento de painéis internos, dashboards, formulários e fluxos operacionais
- Observabilidade e debugging em produção com logs, Grafana, Kubernetes e análise de falhas
- Estruturação de fluxos de CI/CD e apoio a entregas em ambientes com múltiplos serviços
